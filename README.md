# 蓝色孔隙面积分析 · 试用版 0.2.1

**本项目在 [Petrobras GeoSlicer](https://github.com/petrobras/GeoSlicer) 的部分开源算法基础上提取、修改和封装，属于独立衍生工具，不是 GeoSlicer 官方产品。** 保留上游 Apache-2.0 许可证、来源提交及改动声明，详见 [NOTICE](NOTICE) 和 [来源记录](vendor/source-manifest.json)。项目代码按 Apache-2.0 发布。

## 安装与启动

需要 Python 3.11 或以上版本，以及 Tkinter（Windows 官方 Python 安装通常包含）。

```console
python -m pip install -r requirements.txt
python app.py
```

Windows 也可双击 `启动.cmd`。照片、分析结果和个人目录设置不包含在公开仓库中。模型是项目参考区域生成的试用参数，不是 GeoSlicer 官方权重，尚无独立精度验证。

## 0.2.1 性能更新

- 缩放和拖动使用分级图像缓存，只读取屏幕需要的掩膜像素；排除框位置缓存，不再每帧扫描原图。
- 画笔仅更新局部像素计数；原图尺寸的面积计算、自动识别参数和已保存结果不变。撤销、重设排除框时重新核对全图计数。
- 保存复核移到后台，期间仍可缩放和平移；编辑、切图和退出须等保存结束，避免记录不一致。若切图或退出时选择保存，保存完成后请再次切换或退出。
- 初次打开高清图、自动分析和导出高清 PNG 仍需要处理时间。显示缓存不降低原图、统计掩膜或导出图的分辨率。
- 本机 0-4.jpg（5440×3648）两幅 528×354 预览的图像处理，7 次中位耗时约由 550 ms 降至 9 ms；不包含 Tk 窗口绘制，不能解释为整套分析快了同样倍数。

## 停止与继续队列

- 点击 **停止队列** 后，当前图片会先保存完成，再停止。点击 **继续队列**，处理尚未尝试的图片，跳过已完成和失败项。
- 续跑沿用该批次最初的标注区排除设置，结果写入同一个批次目录，汇总包含前后两次的结果。
- 关闭程序后，选择 **打开已有结果**，打开原批次文件夹（含 batch-session.json），再点击 **继续队列**。不需要重新选择原图列表。
- **重试失败** 会在原批次内重新处理失败项，并继续未完成项；成功结果及人工复核版本保留。
- 尚未处理的原图须仍位于原路径。旧批次可从已保存结果恢复队列和设置；若旧批次既没有记录设置，也没有任何完成结果，则需要重新开始。

## 0.2 操作说明

- 关闭旧窗口，再双击 **启动.cmd**。默认字体增大为 13，可在右上角调为 11–20；字号和最近目录会保存。
- 工具栏随窗口宽度换行，左右两图同步缩放。滚轮以鼠标位置缩放，右键拖动平移，“原图100%”按原图像素检查。
- 左边列表切换图片；可选择整个图片文件夹，包含子文件夹。重复选择的同一路径自动去重，不同文件夹同名图片分别保存。
- **打开已有结果**：选择旧批次或单张分析结果目录，不需要重跑识别。原图必须仍在原来的位置。
- **绿色＋橙色**：绿色是计入面积的区域；亮橙色是自动排除、尚未人工决定的蓝色候选。“只看橙色”使用灰底，避免原图颜色干扰。
- 在右侧复核图选择 **加入**，涂过的有效区域计入面积，可补回橙色区域，也可补其他漏检孔隙。
- **橙色转绿色**：仅将画笔范围内尚未决定的橙色候选加入面积，保留候选原有边界，不涂入周围非候选区域；已确认排除的区域不受影响。可按住拖动，支持撤销和保存。建议配合“绿色＋橙色”显示使用。
- 选择 **移除**，涂过的区域不再计入；选择 **确认排除**，仅确认未计入的候选不需要加入，橙色提示消失，面积不会增加。
- 画笔半径使用原图像素，放大倍率不会改变实际画笔大小。每笔结束后更新面积；支持最近20步撤销（Ctrl+Z）。
- **替换排除框**：在右图拖矩形，框内不统计，分母随之更新。新分析可替换默认标注框；旧版结果因缺少框外自动预测，只能在原有效区内进一步排除，无法恢复原先排除区的识别。
- **恢复自动**回到本次原始自动掩膜及初始有效区域，可撤销。不会删除已保存的历史复核版本。
- **保存复核**（Ctrl+S）建立独立版本，保存当前掩膜、有效区、确认排除记录、面积表和可放大的无损PNG报告。重新打开时加载最后保存的复核版本。
- 自动结果保留；人工版本位于图片结果目录的 revisions/。current_review.json 指向最近完整保存的版本。
- 分析过程中可查看和编辑已经完成的照片，批次结束后再保存复核。停止队列会等当前图片保存完成；失败项可重试。
- 切换照片或退出时，会提示保存未保存修改。保存复核不代表已经得到独立验证的真实孔隙率。

旧HTML报告不会自动变化。可以在新版程序中打开旧结果并保存复核，生成显示清晰的新报告；无需重新识别。

## 自动分析

双击 **启动.cmd**。选择一张或多张染色照片，点击“开始分析”，选择保存位置。
工具会建立独立的新文件夹，保存面积表、掩膜、识别叠加图与 HTML 报告。
图像在本地处理，不上传，不修改源照片。同名照片分开保存。

绿色表示计入统计的蓝色像素；橙色表示颜色像蓝色、但被分类器或边缘规则排除的区域，需要复核。橙色占比不是误差范围，也不应直接加到面积率上。

## 来源与改动

实际抽取 Petrobras GeoSlicer 的 `create_stencil_mask` 和 `bayesian_inference`，原始提交为 `c849620433dc36fd1c78cc93f0aa33c32e5b8f54`。
原文件：`src/modules/Segmenter/BayesianInferenceCLI/BayesianInferenceCLI.py`。
许可、原文件散列和源代码网址保存在 vendor/，许可证为 Apache 2.0。

保留贝叶斯邻域似然计算；移除 Slicer/VTK 界面及体数据读写依赖。
本工具只调用二维、3×3、cubes、stride=1 路径，采用带重叠边缘的分块计算。
其余上游路径（例如大核 FFT）不支持，不作为公开接口调用。

参数由本项目 0-1、3-10、4-16 三张图中的少量参考区域训练；参考区域为本次 GPT 原生看图后标注，**未经过实验人员确认**。位置、类别和样本数见 model-reference.json。
**没有使用 GeoSlicer 官方预训练权重，也不声称与官方模型效果相同。**

改进：结合邻域颜色与纹理分类；要求局部蓝色核心，再保留相邻的候选蓝色像素，以抑制窄色带；可把排除的蓝色候选显示为橙色。
不自动把孔内暗点填成孔隙。孤立细孔、细裂缝和浅蓝过渡可能漏检。

## 统计口径与限制

- 面积率 = 计入的蓝色像素 / 有效视场像素 × 100%。分母包含骨料与基体。
- 默认排除右下角最后 9% 宽 × 9% 高的标注区，可取消。该区域也包含少量真实材料。
- 为快速处理，推断图宽最大 1600 像素，再将掩膜按最近邻映射回原尺寸统计。不能把这个结果称作原分辨率下独立预测。
- 无需标尺即可计算面积百分比；本版不输出实际孔径或物理面积。
- 本工具针对当前染色照片制作。照明、染色或材料变化后必须重新检查；尚不能直接用作正式研究孔隙率测量。
- 原生目视检查是复核，不是独立人工真值；没有已验证的 Dice/IoU/准确率。
